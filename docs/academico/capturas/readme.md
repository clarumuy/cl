# capturas

Las imágenes `vista-previa-*.png` muestran el diseño de la interfaz con **datos de ejemplo**. Las generamos usando los estilos del proyecto para que se entienda cómo es el panel. No son pruebas de que el servidor o el apagado funcionaron.

Para la entrega final con evidencia real debemos sacar capturas después de levantar el proyecto en un entorno de prueba: inicio de sesión, laboratorios, computadoras, solicitudes pendientes, estados y resultado de la prueba en equipos autorizados. Guardamos esas capturas aquí sin mostrar contraseñas, tokens ni datos personales.
