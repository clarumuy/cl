# documentación

Acá dejamos la consigna, el informe y las guías para poder explicar e instalar el trabajo sin depender de alguien del grupo.

- `consigna/`: PDF que nos entregaron.
- `academico/`: informe, diagramas, requisitos, capturas de diseño y defensa.
- `desarrollo/`: cómo organizamos el código y la comunicación.
- `operacion/`: instalación, uso y actualización.

Tratamos de que cada archivo explique una parte concreta y no repetir las mismas instrucciones en cinco lugares.

También dejamos [qué revisamos y qué falta comprobar en máquinas reales](desarrollo/verificacion.md).
